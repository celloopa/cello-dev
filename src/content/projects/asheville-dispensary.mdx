I've led design for Asheville Dispensary, Plantbar and Nightshade since 2022, from social posts and banners to signs, packaging and slides. I'm building all three brands from one set of shared layouts, templates and interface pieces, so the team can find the approved file and each brand still looks like itself.

## Where are the approved files?

In one searchable library, with a portal in each brand's look.

Before, finding an approved file meant knowing the right folder or remembering an old link.

The three portals share one layout, one search, the same categories and the same interface parts. Each takes its colors and type from its own brand. When I improve the shared layout, all three portals get the change.

The people who run it can add brands, categories and links without code.

## Won't shared parts make the brands look alike?

The brands share what each piece of a design is for, and each brand decides how it looks.

A heading does the same job in all three brands without using the same typeface. A button sits in the same place in the hierarchy and takes its color from the brand.

So Asheville Dispensary keeps its forest green. Plantbar keeps its own palette and type. Nightshade keeps the blue and pink from its earlier work.

Each brand has its own editable guide, so its identity and approvals stay easy to follow.

## Why didn't the old files agree?

Some differences were on purpose, and others crept in over time. The brands' guides, live websites and working templates didn't always match.

A color in a guide might differ from the one on the live page. An older template might use a typeface from an earlier direction.

So I go through them one at a time: where each one came from, what doesn't match, whether it's deliberate, and what needs sign-off before it becomes the rule.

## Can one event post become a sign?

The content can. The layout changes with the format.

An event announcement needs a title, a date, a venue, the details and a way to act on it. That stays the same whether it lands on a phone story, a web banner, a printed sign or a slide.

On a phone, the edges get cropped and the app's own buttons cover parts of the screen. A printed sign needs real measurements and a print-ready file. Each format gets its own type size and density.

The template proposals spell out what someone can edit, what stays controlled, and the hard cases: a long headline, a packed lineup, a missing photo, an event that gets cancelled.

## What's working today?

The guides and template proposals are in review, and the next step is moving the print and social templates onto the shared layouts once they're approved.

The file library is in use for all three brands. The weekly flower-drop stories are one place the shared layouts already show up: one design, a new product each week. Their redesign is in [Automating product drops gave me time to redesign them](/blog/scheduled-agent-flower-drop-routine/).
