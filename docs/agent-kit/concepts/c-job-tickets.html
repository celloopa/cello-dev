Rate card

What to pay for and what to run locally. [Cello's words]

ItemPayLocalSkip
Claude planThe one worth paying for. Parallel workers use a lot, so a higher tier keeps the pipeline from stalling.
Local modelsPrivate chores: summaries, transcription, AI features inside your apps. Not a replacement for Claude as the coder.
ImagesComfyUI runs free on a decent GPU. A ChatGPT plan helps with text in images and adds Codex as a second coder.
Firecrawl, MobbinSkip at first. Built-in web search and screenshots of apps you like cover personal projects.
HostingYour own computer or home server is free. Rent a small server only when apps must run while yours is off.
App storesNot needed. Web apps install to phone home screens.
