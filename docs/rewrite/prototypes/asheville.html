One system, three brands

I lead design for three cannabis brands: Asheville Dispensary, Plantbar and Nightshade. Each one has to look like itself. They're all designed from one shared Figma system, and the rule is simple: the structure is shared, and each brand brings its own identity.

Stays shared across the brands

  • Spacing and layout patterns.
  • Components: cards, category tiles, search and forms.
  • How things are organized: brands, categories, tags.

Changes with each brand

Its color, set by the brand's own tokens (CSS custom properties in code).

Prototype ends here. The full case study is live at cello.design/projects/asheville-dispensary.
